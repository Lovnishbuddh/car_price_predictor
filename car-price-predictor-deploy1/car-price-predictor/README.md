# Car Price Predictor using Machine Learning

An end-to-end machine learning project that predicts the **resale price of a
used car in Indian Rupees (Rs)** from its specifications, served through a
modern, responsive Flask web application.

Built as an AI & Data Science internship project.

---

## What it does

Enter a car's **company, model, year of purchase, kilometres driven and fuel
type** on the website, click **Predict Price**, and the trained machine
learning model instantly returns an estimated market price.

- Real model, real data - **nothing is hardcoded**
- Predictions in Indian Rupees with Indian number formatting (Rs 4,25,000)
- Input validation in the browser AND on the server
- "Project Details" page with workflow, metrics and EDA charts

## Results (measured, not invented)

| Model | R2 (test) | MAE | RMSE | 5-fold CV R2 |
|---|---|---|---|---|
| Linear Regression | 0.7562 | Rs 1,27,029 | Rs 1,87,788 | 0.6974 |
| Random Forest | 0.7607 | Rs 97,097 | Rs 1,86,059 | 0.7454 |
| **Extra Trees (selected)** | **0.7863** | **Rs 83,572** | **Rs 1,75,805** | **0.7659 +/- 0.0506** |

The best model explains roughly 77% of price variation; on average its
predictions are within about Rs 84,000 of the true listing price.

## Dataset

`dataset/quikr_car.csv` - used-car listings scraped from **Quikr.com**
(892 raw rows). The dataset is intentionally messy, so data cleaning is a
highlight of this project:

| Problem in raw data | Fix applied |
|---|---|
| 35 rows with `Ask For Price` instead of a number | removed |
| Years like `r 15`, `TOUR`, `150k` | only 4-digit years 1995-2020 kept |
| Prices as comma strings, one impossible `85,00,003` | parsed to numbers, range 30k-30 lakh |
| Kilometres as `45,000 kms` text, blanks, a 4,00,000 km outlier | parsed, blanks dropped, capped at 2,50,000 |
| 55 rows missing fuel type | removed |
| `MARUTI` / `tata` / `Maruti`, fake sellers like `URJENT` | case-normalised, brands with < 5 listings dropped |

**After cleaning: 797 rows, 18 brands, 242 models.**

## How to run (on your laptop)

### 1. Install Python 3.10+ and the dependencies

```bash
pip install -r requirements.txt
```

### 2. (Optional) Re-run the ML pipeline yourself

```bash
# from inside the project folder:
python -m src.preprocess     # self-test of the cleaning rules
python -m src.eda            # regenerate the EDA charts
python -m src.train_model    # retrain, compare models, save car_price_model.joblib
```

### 3. Start the web app

```bash
python app.py
```

Open **http://127.0.0.1:5000** in your browser. That's it.

> The saved model (`models/`) is already included, so the website works
> immediately. Re-running training overwrites it with identical results
> (fixed `random_state=42`).

## How to test

1. **Homepage loads** with all dropdowns populated from the training data.
2. **Happy path**: Hyundai / Hyundai i20 Sportz / 2014 / 28000 / Petrol
   -> shows a price around Rs 2,07,000.
3. **Validation**: click Predict with an empty form -> red error messages
   under every empty field (and again on the server if JS is bypassed).
4. **Unseen car**: a model not in the training data still returns a sensible
   price (thanks to `OneHotEncoder(handle_unknown='ignore')`).
5. **Responsiveness**: open the site on a phone-width window - the form
   reflows to a single column.

## Limitations (be honest in your presentation!)

- ~800 rows is a small dataset; rare brands are learned poorly.
- Features are limited - no transmission, owner count, city or accident
  history in this dataset.
- Listings are from one website and a few years old; retrain for current
  prices.
